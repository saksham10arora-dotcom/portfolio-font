Saksham Card

A typeface where certain words stop being words. Type a project name in lowercase and an OpenType ligature swaps the whole sequence for a single glyph that draws that project's card. Type it in capitals and it stays ordinary letters.

saksham

WHAT IT ACTUALLY IS

Every glyph is drawn from a pixel grid, and each card is one glyph, not a picture. It is a real .ttf: install it and the ligatures fire in any application that shapes OpenType text, including Figma, Word and your terminal.

Lowercase and uppercase are separate glyphs on purpose. The substitution rules are bound only to the lowercase ones, which is what lets saksham become a card while SAKSHAM stays readable.
